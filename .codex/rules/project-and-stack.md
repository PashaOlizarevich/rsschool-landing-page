# Проект и технический стек

## Перед началом работы

1. Изучи структуру каталога и относящиеся к задаче файлы.
2. Для требований задания проверь актуальные README-part-1.md, README-part-2.md и cross-check-файлы.
3. После появления исходного кода определи фактический стек, команды, линтер и форматтер по конфигурации и lock-файлам.
4. Проверь Git-статус и текущую ветку, если каталог является Git-репозиторием.
5. Не считай Vite, npm, Sass или другую технологию используемой без подтверждения в проекте или явного решения пользователя.

## Ограничения задания

- Используй HTML, CSS и чистый JavaScript.
- TypeScript запрещён.
- React, Vue, Angular и другие JavaScript-фреймворки запрещены.
- CSS-фреймворки, включая Bootstrap, запрещены.
- Готовые библиотеки компонентов и интерактивности запрещены.
- Burger menu, slider и modal реализуются самостоятельно.
- Sass/SCSS, modern-normalize и сборщики допускаются только после согласования с пользователем.
- При использовании сборщика включи source maps.
- Код должен оставаться читаемым, неминифицированным и необфусцированным.
- Нельзя заменять интерфейс или его секции скриншотами макета.

## Границы изменений

- Не меняй файлы вне Project coffee без прямого запроса.
- Не устанавливай зависимости без разрешения.
- Не расширяй область задачи без разрешения.
- Не удаляй материалы макета.
- Не переписывай готовую часть проекта без необходимости.
- Сохраняй несвязанные изменения пользователя.
- Не читай, не выводи и не сохраняй секреты, `.env`, токены, cookies, пароли и персональные данные.
- Если требование задания расходится с пожеланием пользователя, покажи конкретное противоречие до реализации и запроси решение.
