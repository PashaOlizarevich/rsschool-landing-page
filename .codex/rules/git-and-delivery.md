# Git и сдача задания

## Репозиторий и ветки

- Репозиторий задания: rsschool-landing-page.
- Ветка main остаётся пустой, кроме служебных файлов.
- Часть 1 выполняется в landing-page, Pull Request открывается в main и не мержится.
- Часть 2 выполняется в landing-page-part-2, созданной от landing-page.
- Pull Request второй части открывается в landing-page и не мержится.

## История и сдача

- История коммитов отражает реальные этапы разработки.
- Сообщения коммитов соответствуют Git Convention RS School.
- Для каждой части нужен актуальный публичный деплой, доступный в режиме инкогнито.
- В Pull Request указываются выбранный вариант Coffee House и ссылка на актуальный деплой.
- Перед сдачей проверь требования актуального задания и cross-check, поскольку они могут измениться.

## Ограничения для агента

Не выполняй commit, push, merge, создание Pull Request или деплой без прямого указания пользователя.
