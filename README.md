# Coffee House — Landing Page

Учебный проект RS School: адаптивный двухстраничный сайт кофейни
по готовому макету Coffee House.

## Технологии

- HTML5
- CSS3
- JavaScript

## Часть 1 — Вёрстка

- Главная страница и каталог.
- Адаптивная вёрстка для экранов от 380 до 1440 px.
- Светлая и тёмная темы.
- Сохранение выбранной темы в localStorage.

Код первой части находится в ветке `landing-page`.
Pull Request направлен в `main` и остаётся открытым для проверки.
